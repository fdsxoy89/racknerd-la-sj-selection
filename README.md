## 下单前容易踩的五个坑

**1. DC-02 会断货。** 每次大促放出来，通常几天内被抢空。看准了就直接上 2GB 或 3.5GB，犹豫到第二天可能就只剩圣何塞。

**2. 促销价不叠加优惠码。** 年付特价方案结账时直接是底价，优惠码用在常规 KVM、Windows VPS 和独立服务器上，比如 `WIN-30OFF` 是 Windows VPS 终身 7 折、`15OFFDEDI` 是独服 85 折。别指望在 $18.29 上再打一次折。

**3. 促销套餐不能直接换机房。** 买完发现选错机房，只能另购一台再用 rsync 或 scp 迁数据，官方不给直接迁移。

**4. IP 被墙有 72 小时窗口。** 购买后 72 小时内可以免费更换 IP，之后换一次收 $3。拿到机器第一件事是测 IP 通不通，再开始部署。
